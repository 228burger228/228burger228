### 👨‍💻 Engineering & Design Philosophy

- **Zero-Bloat & Deletion-First:** Clean semantic HTML5, modern CSS (Grid / Flexbox / Container Queries), and Vanilla JS ES2024. No heavyweight frameworks where native browser APIs run 10x faster and lighter.
- **Design Systems into Pixel-Perfect Code:** Creating modular UI tokens and prototypes in **Figma**, then executing them cleanly into code with micro-interactions, dark themes, and high-contrast typography.
- **Modern AI & Search Readiness:** Architecting projects for both human UX and AI agents — implementing `/llms.txt`, Schema.org structured data, and LLM-ready context.
- **Beyond Frontend:** Real-time 3D WebGL (Three.js), procedural 2D Canvas physics, Python/Playwright automation, and high-performance Telegram microservices.
